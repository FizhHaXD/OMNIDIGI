## 🛡️ BONUS: CHEAT SHEET ANTISIPASI PERTANYAAN JURI (Q&A)

Jika dewan juri menanyakan tentang bagian admin yang kamu bawakan, gunakan jawaban taktis berikut:

### Q1: *"Bagaimana kalian menjamin keamanan data pelanggan di dashboard admin?"*
> **Jawaban Hafizh:**  
> *"Kami menerapkan prinsip pertahanan berlapis (defense-in-depth), Pak/Bu. Pertama, autentikasi dilindungi oleh Role-Based Middleware (`AdminMiddleware`), sehingga akun pelanggan biasa tidak akan pernah bisa mengakses endpoint `/admin`. Kedua, seluruh password di-hash menggunakan algoritma Bcrypt standar industri. Ketiga, query database menggunakan Eloquent ORM dengan parameter binding sehingga 100% terlindung dari serangan SQL Injection."*

### Q2: *"Kenapa perlu ada fitur AI-Ready Document Generator? Mengapa tidak pakai template cetak biasa?"*
> **Jawaban Hafizh:**  
> *"Tantangan di lapangan adalah setiap kasus pelanggan itu unik—ada pelanggan yang menunggak 1 bulan, ada yang menunggak beserta denda, dan ada lokasi padam yang membutuhkan penanganan darurat spesifik. Dengan arsitektur JSON Schema AI-Ready, AI Agent dapat membaca konteks data pelanggan secara presisi lalu merangkai narasi surat atau pesan WhatsApp broadcast yang sopan, solutif, namun tetap tegas dan berpayung hukum ESDM, tanpa risiko salah ketik oleh manusia."*

### Q3: *"Bagaimana cara sistem mendeteksi anomali pada pencatatan SwaCAM?"*
> **Jawaban Hafizh:**  
> *"Sistem kami membandingkan angka stand meter yang diinput pelanggan dengan batas rata-rata historis golongan dayanya. Jika konsumsi melebihi 400 kWh per bulan untuk golongan rumah tangga kecil, atau jika angkanya justru lebih rendah dari angka bulan lalu (indikasi meteran macet atau salah baca), sistem admin secara otomatis menyematkan label 'Anomali Terdeteksi' agar petugas melakukan kroscek sebelum tagihan dicetak."*
